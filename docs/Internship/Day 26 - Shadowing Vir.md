##### Date: 03/05/2026
##### Hours Completed: 4.5 hours

Day-to-day work varies depending on the pace of incoming tasks. Much of the work is driven by Nova notes, and on slower days the focus shifts to routine security scanning using Tenable Nessus and working through checklists in Epic UserWeb to ensure systems stay compliant and up to date. Any pressing issues that come up take priority as they arise.

Project work is tied to Epic's release cycle, picking up significantly when new versions or major features roll out. Current projects include a tiered storage initiative, which involves working with BLOB storage as the file format structure, and hardening load balancers across the environment. The load balancer work centers on NetScaler ADCs — application delivery controllers — which manage traffic between internal and external networks through content switching policies. 

Because storage on these devices is limited, logs must be cleared before upgrades can be performed. The environment is split across four NetScalers: NS1 and NS2 sit in the DMZ, while NS3 and NS4 form a separate pair dedicated to Epic-specific traffic, helping enforce the boundary between internal and external network zones.
