Around 45 minutes later, the Help-desk Supervisor (Tony) got a request for four computers to be moved around at the FHA clinic. We disconnected the monitors, hub, mouse, keyboard, and cables; then reconnected everything and checked if everything worked by plugging in a laptop to check the monitors! Easy move.

When we came back to HQ, I shadowed the Systems Admin (Ryan). He showcased different applications like RoyalTS, AD, Entra, and Purview. For some context, the IT Manager (Derrick) got a suspicious email and reported it to Ryan for him to delete the item. The reason Ryan needed to delete the email instead of Derrick is because one; it's standard procedure, and two; if multiple people receives the same email with the same sender then Ryan can remove all of them at once instead of relying on everyone to delete it themselves. Giving the System Admin the responsibility to remove suspicious emails reduces risk and limits the possibility of an accidental insider threat. 

While Ryan was showing us how to remove the email, there were some obstacles in the way. For example, Microsoft loves to change up their different services and so it can be difficult to be an expert in the Microsoft Admin Center. The goal was to query the email on Purview and delete it using powershell, but for some reason when listing the item to validate if the query existed, it showed 0 items. So googling was involved! He searched up official Microsoft documentation, showing different powershell commands (including how to query the email without using the Purview GUI). So, by pivoting to only using ~6 powershell commands, Ryan was able to remove the suspicious email for Derrick. cli > gui.  

After shadowing, I completed the new hire on-boarding checklist. Simple items; reading policies and signing agreements.
